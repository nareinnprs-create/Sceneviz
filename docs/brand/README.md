# SCENEVIZ Brand Kit — v1.0

Core brand: SCENEVIZ
Tagline: IDEAS INTO MOVING WORLDS.
Direction: cinematic premium, professional + social/marketing creators.

## Contents
- 01_logo: editable SVG logo concept, app icon concept, monochrome lockup concept.
- 02_brand_system: palette JSON and SVG color swatches.
- 03_social_templates: three editable SVG social layouts.
- 04_product_ui: CSS design tokens for light and dark themes.
- 05_guidelines: master brand guidelines PDF.

## Important
The emblem and wordmark are the approved Sceneviz v1.0 master identity. The abstract "Z" emblem (`sceneviz_app_icon_concept.svg` / `sceneviz_primary_concept.svg` / `sceneviz_monochrome_concept.svg`) is the canonical mark; Cinematic Amber `#F2AE43` is the official accent.

Typography: Space Grotesk (display), Inter (UI), JetBrains Mono (technical).
Social templates are editable layout starters, not finished campaign artwork. Replace abstract background geometry with approved campaign imagery where appropriate.
Validate contrast and accessibility before shipping. Check trademark availability and logo similarity in target markets before launch.
